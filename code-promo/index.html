CODES PROMO & RÉDUCTIONS

Un code promo ?
Voici la liste officielle.

Carte CEZAM, Trip Normand, CSE, tickets, chèques-vacances, étudiant·es, mariage… Trouvez votre code, saisissez-le à la réservation et apportez le justificatif le jour J. C'est tout.

Un code = un justificatif

Chaque code de cette page correspond à une carte, une adhésion, des tickets ou une situation précise. Le justificatif est contrôlé à l'accueil, à l'arrivée de votre équipe.

Sans justificatif valable, la remise saute : la différence avec le tarif normal est à régler sur place, avant le début de la session. Les codes qui circulent sur les sites de bons plans ne sont pas valables.

Mode d'emploi

Où saisir votre code ? En 2 minutes.

Le code se saisit en ligne, avant le paiement, dans le champ prévu sur la page de commande.

Réservez comme d'habitude

Activité, date, heure, nombre de joueurs, puis Continuer ma réservation.

Repérez le champ code

Sur la page Récapitulatif de Commande, après vos coordonnées et les options de la séance, juste au-dessus du montant : le champ Code promo ou Bon cadeau.

Saisissez, appliquez

Tapez votre code (ex. CEZAM) puis Appliquer : le montant à régler se met à jour.

Payez, puis justifiez

Procéder au paiement et réglez en ligne. Le jour J, montrez le justificatif à l'accueil.

FAQ codes promo

Questions fréquentes — Codes promo & réductions

Où saisir mon code promo lors de la réservation ?

Réservez en ligne sur braincaen.4escape.io/booking : choisissez votre activité, la date, l'heure et le nombre de joueurs, puis « Continuer ma réservation ». Sur la page « Récapitulatif de Commande », après vos coordonnées, le champ « Code promo ou Bon cadeau » se trouve juste au-dessus du montant : saisissez votre code et cliquez sur « Appliquer ». Le montant à régler se met à jour, avant le paiement.

Que se passe-t-il si je n'ai pas le justificatif le jour J ?

Le justificatif est contrôlé à l'accueil, à l'arrivée de votre équipe. Sans justificatif valable, la différence avec le tarif normal est à régler sur place, avant le début de la session (article 5 des CGV). Pensez à prévenir tout le groupe la veille.

Puis-je cumuler plusieurs codes ou réductions ?

Non : les réductions ne se cumulent pas. Un seul code par réservation. Le code MARIAGE n'offre qu'une seule place, celle de la mariée ou du marié.

Les codes promo GAMEDOOR·41 trouvés sur des sites de bons plans sont-ils valables ?

Non. Les seuls codes valables sont ceux de cette page, et chacun exige un justificatif présenté à l'accueil. Les codes qui circulent sur les sites de coupons sont périmés, personnels ou inventés : la réservation est alors recalculée au tarif normal, à régler sur place avant de jouer.

Comment payer avec des chèques-vacances ANCV ?

Avec des chèques-vacances papier, réservez avec le code ANCV : vous ne payez rien en ligne et vous remettez vos chèques à l'accueil pour régler la session. Les chèques-vacances ne donnent pas lieu à un rendu de monnaie ; un éventuel complément se règle sur place.

Ma carte cadeau se saisit-elle au même endroit ?

Oui : le code unique de votre carte cadeau GAMEDOOR·41 (reçu par e-mail ou dans le Coffret Mystère) se saisit dans le même champ « Code promo ou Bon cadeau ». Son montant est déduit ; un éventuel solde reste utilisable pendant un an.

Y a-t-il un code pour les entreprises, CSE ou associations ?

Pas de code : les tarifs professionnels (escape 17,50 € TTC/pers, quiz 15 € TTC/pers) s'obtiennent sur justificatif Kbis / SIRET ou bon de commande, via un devis. Les salarié·es d'un CSE partenaire utilisent le code de leur CSE, indiqué dans la liste.
